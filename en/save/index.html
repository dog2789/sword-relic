Move Save

Export your progress as a code or a file and import it in another browser, the PC app or the phone app. Handy as a backup too.

This device's save

Import a save

Paste a copied code, or choose a saved file.

Save to import

Importing overwrites the save on this device. Your current save is kept aside so you can restore it once.

How to move it

  1. Where you were playing (e.g. the web), open this page and click Copy code.
  2. Send the code to yourself, by email or a chat app.
  3. Where you want to play (e.g. the phone app), open Settings → Move Save in the game, paste it and overwrite.
